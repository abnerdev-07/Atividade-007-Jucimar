# FSI-Tutorial-Flask
## Atividade-007-Jucimar - Criar um gerenciador de tarefas usando python/flask

Refaça o to-do list

- crie um novo repositório para seu projeto e acrescente os colaboradores

- crie uma lista de contantos
- as tarefas deverão ser atribuidas a um contato. elas podem ser apagadas
- cada tarefa tem uma descrição, prazo, prioridade e status ( a fazer, fazendo, concluída ou atrasada ). cada status uma cor diferente
- ha uma tela para visualizacao das tarefas com seus respectivos responsáveis
- crie um cronograma para seu projeto ([https://www.youtube.com/watch?v=CWn-eieoRpQ](https://www.youtube.com/watch?v=CWn-eieoRpQ)) e atribua as tarefas

**obs1: selecionem, com sabedoria, um líder para o grupo. o lider do projeto é responsável pela entrega do trabalho e pelas atividades** **dosmembros. ele deverá conferir se os membros estão executando suas tarefas no dia/hora marcados**

**obs2: sem commit importante, sem nota**
